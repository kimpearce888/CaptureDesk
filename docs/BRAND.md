# CaptureDesk — Brand & Design System (v1.0)

## 1. Naming rules (NON-NEGOTIABLE)

- The product is named **CaptureDesk**. Full stop.
- No other screen-recording product's name, brand, or trademark may appear
  anywhere in this repository: not in code, comments, UI text, package names,
  file names, docs, README files, installer strings, registry entries, or
  URLs. This document itself must contain zero occurrences of them.
- Forbidden anywhere: any competitor product name, or derivatives such as
  "X-like", "X Clone", "X Alternative", "X Extension", "X Recorder" for any
  such name X. Refer to feature *categories* instead ("screen recording",
  "browser-tab recording", "webcam recording", …).
- Canonical asset names:
  - Chrome extension (store/manifest name): `CaptureDesk`
  - Desktop application: `CaptureDesk` (window titles: `CaptureDesk`, `CaptureDesk Editor`, `CaptureDesk Settings`)
  - Installer: `CaptureDeskSetup.exe`
  - Extension bundle: `CaptureDesk-Chrome-Extension.zip`
  - App data directory: `CaptureDesk/` (userData)
  - Recordings: `CaptureDesk_YYYY-MM-DD_HH-mm-ss.webm`
  - Packages: `capturedesk-extension`, `capturedesk-desktop`,
    `capturedesk-native-host`, `capturedesk-installer`, `capturedesk-editor`
  - Deep link protocol (desktop): `capturedesk://`
- UI strings to use (exact style): "Start Recording", "CaptureDesk Settings",
  "CaptureDesk Recordings", "CaptureDesk Editor", "CaptureDesk Export",
  "CaptureDesk Desktop", "CaptureDesk is ready".

## 2. Visual identity (original)

The identity is an original design: a **teal→deep-cyan rounded square badge**
containing a **white monitor frame with a recording-dot badge** and a stand.
Do not imitate any other recorder product's logo, logo shape, exact colors,
illustrations, UI artwork, or icons.

### Palette

| Token            | Hex       | Usage                                    |
|------------------|-----------|------------------------------------------|
| `--brand-500`    | `#14B8A6` | Primary teal (buttons, active states)     |
| `--brand-600`    | `#0D9488` | Hover / pressed                           |
| `--brand-300`    | `#5EEAD4` | Light accents, focus rings                |
| `--cyan-700`     | `#0E7490` | Gradient end, secondary accents           |
| `--slate-950`    | `#0B1120` | App background (dark UI)                  |
| `--slate-900`    | `#0F172A` | Surface / panels                          |
| `--slate-800`    | `#1E293B` | Cards, inputs                             |
| `--slate-700`    | `#334155` | Borders                                   |
| `--slate-400`    | `#94A3B8` | Secondary text                            |
| `--slate-100`    | `#F1F5F9` | Primary text                              |
| `--rec-500`      | `#EF4444` | Recording indicator ONLY (timer, dot)     |
| `--amber-400`    | `#FBBF24` | Highlights, warnings                      |

Gradient for hero/brand moments: `linear-gradient(135deg, #14B8A6, #086E96)`.

### Typography

- System stack: `"Segoe UI Variable Display", "Segoe UI", system-ui, -apple-system, "Noto Sans", sans-serif`
- Numbers/timers: `font-variant-numeric: tabular-nums`
- Scale: 12 / 13 / 14 (base) / 16 / 20 / 28 / 36. Headings weight 650–700,
  body 400–450. No external font downloads — system fonts only.

### Shape, spacing, motion

- Corner radius: 10px (controls), 14px (cards), 20px (modals/hero).
- Spacing grid: 4px base; page padding 24px.
- Motion: 150ms ease-out for hovers; 220ms for panels. Recording pill uses a
  subtle 2s pulse on the red dot only.
- Elevation: soft shadows `0 8px 24px rgba(2, 12, 27, .45)`.

### Iconography

- Inline SVG line icons, 1.6px stroke, round caps (no external icon fonts).
- The logo (monitor + rec-dot badge) lives in `assets/` as PNG at multiple
  sizes; UI may re-draw it as inline SVG using the same geometry.

## 3. Voice & microcopy

- Confident, friendly, concise. Sentence case for buttons ("Start Recording",
  "Stop & save").
- Status phrases: "CaptureDesk is ready", "Recording…", "Paused", "Saved to
  your Recordings folder".
- Errors are actionable: "Microphone unavailable — recording without audio."
- No marketing fluff inside the product UI.

## 4. Trademark hygiene checklist (run before every release)

1. Search the whole repo (excluding `node_modules`, `build`, `dist`) for every
   forbidden competitor name listed in section 1 — case-insensitive — and fix
   any hit until the count is 0. This document must also stay clean.
2. Product strings say CaptureDesk (never shortened to "CD" or "Desk").
3. Icons/illustrations are only the ones generated by `scripts/gen-icons.py`.
